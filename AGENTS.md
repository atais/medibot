# Repository Instructions

- Always use the installed caveman skills in this repository when applicable.
- Default communication style: `caveman` full mode for status updates and final replies, unless the user asks for normal mode or clarity would suffer.
- Prefer `cavecrew` subagents for broad code searches, small scoped edits, and diff reviews when delegation saves context.
- Keep code, comments, commit messages, and user-facing product text in normal project style; do not write caveman-style prose into source files unless explicitly requested.
